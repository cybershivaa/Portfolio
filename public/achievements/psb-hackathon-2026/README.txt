Place the PSB Hackathon Series 2026 photos in this folder.

Naming: 1.jpg, 2.jpg, 3.jpg, ... (any number of photos)
Paths used by the site: /achievements/psb-hackathon-2026/1.jpg  (etc.)

To add, remove, or reorder photos, edit the `images` array of the
"psb-hackathon-2026" entry in: src/data/achievements.ts

Other formats (.png / .webp / .jpeg) work too — just use the matching
file extension in the `images` array.
