Place the Global Fintech Fest 2026 photos in this folder.

Naming: 1.jpeg, 2.jpeg, 3.jpeg, ... (any number of photos)
Paths used by the site: /achievements/global-fintech-fest-2026/1.jpeg  (etc.)

To add, remove, or reorder photos, edit the `images` array of the
"global-fintech-fest-2026" entry in: src/data/achievements.ts

Other formats (.png / .webp / .jpeg) work too - just use the matching
file extension in the `images` array.
